# Lista de Exercícios - Laços e Condicionais em Java
 
Lista de 40 exercícios em Java combinando estruturas de repetição (for, while, do-while) com estruturas condicionais (if/else, switch-case).
 
## Parte 1 - Números e laços básicos (1-10)
 
Pares e ímpares, soma de pares e ímpares, FizzBuzz, contagem de primos, fatorial com validação, números perfeitos, Fibonacci, contagem regressiva, simulação de saque bancário.
 
## Parte 2 - Cálculos numéricos com laços e condições (11-20)
 
Tabuada seletiva, maior e menor valor, classificação de notas, aprovados x reprovados, palíndromo numérico, número de Armstrong, contagem e soma de dígitos, inversão de dígitos, sequência de Collatz.
 
## Parte 3 - Textos, break e continue (21-26)
 
Contagem de vogais, maiúsculas e minúsculas, palavra palíndroma, uso de break e continue.
 
## Parte 4 - Simulações, menus e desvios de fluxo (27-40)
 
Jogo de adivinhação, juros compostos, anos bissextos, menu de calculadora, positivos/negativos/zeros, pirâmide de asteriscos, tabela Celsius-Fahrenheit, MDC, MMC, sequência crescente, fila de atendimento, potência sem Math.pow(), números triangulares, sistema de login.
 
## Como executar
 
Projeto desenvolvido na IDE IntelliJ IDEA. Basta abrir o projeto na IDE e rodar cada classe individualmente.
 
Também é possível compilar e executar via terminal:
 
```bash
javac NomeDoArquivo.java
java NomeDoArquivo
```
 
## Tecnologia
 
Java, IntelliJ IDEA
